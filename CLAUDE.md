# Space Apps 2026: Earth Analogs for Moon and Mars

## What this project is
Our team's entry for the NASA Space Apps Challenge 2026 challenge "Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars."
We score Earth sites against Moon and Mars targets (an Artemis III south pole region and a Mars ice landing zone) on several dimensions, then show the results as an interactive map and a radar chart per site.
Deadline: Sunday Nov 15, 11:59 PM local time. Simple and working beats ambitious and broken.

## Stack (do not add anything else)
- Python 3 with pandas, folium, plotly only.
- No JavaScript frameworks, no servers, no databases.
- The output is static HTML files in `docs/`, published by GitHub Pages.

## Folder layout
- `data/site_options.csv`, `targets.csv`, `earths_limits.csv`, `mission_tasks.csv`, `datasets.csv`:
  the tabs of our research Google Sheet, exported as CSV. These are the real inputs.
- `data/import_sheet.py`: turns `site_options.csv` + `targets.csv` (+ `power_skin_temps.csv`) into `data/sites.csv`.
- `data/fetch_power.py`: downloads NASA POWER skin temperatures per site into `data/power_skin_temps.csv` (uses the internet; run only when sites change).
- `data/scores_html.py`: the "Similarity scores" cards on site pages, and the NASA POWER citation.
- `data/sites.csv`: generated by import_sheet.py. One row per site or target. Don't hand-edit.
- `data/score.py`: computes the 0 to 1 similarity scores per dimension; checks the data.
- `data/pages.py`: shared HTML helpers and site pages. `data/topic_pages.py`: gap, task and About pages.
- `data/compare_page.py`: the Compare sites page (all sites side by side, one condition at a time).
- `data/style.css`: the look of all pages except the map; build.py copies it to `docs/style.css`.
- `data/build.py`: runs everything, writes `docs/index.html` (map with Moon/Mars filters), a page per site, `docs/compare.html`,
  `docs/gap.html`, `docs/tasks.html` and `docs/about.html`.
- `docs/`: generated website. Do not hand-edit generated files.
- `notes/`: site write-ups and citations (plain markdown).

## CSV columns (data/sites.csv)
name, type (earth / moon_target / mars_target), lat, lon, slope_deg, temp_max_c, temp_min_c, temp_range_c, precip_mm_yr, dust_aod, matches, breaks, source_links, category, analog_for, mission_tasks, key_facts, climate_notes, geology, how_well_studied
- Text columns are copied word for word from the Sheet.
- Scoring columns (slope_deg ... dust_aod) are only filled from Sheet columns with exactly those names, holding plain numbers, ground-surface values only. Never pull numbers out of text such as "<30" or "80.8 (surface, MODIS)".
- Exceptions, listed in import_sheet.py: `temp_max_c` for Earth sites comes from `data/power_skin_temps.csv` (NASA POWER annual TS_MAX, made by `data/fetch_power.py`); for targets it comes from the Targets tab column "Max ground surface temp (°C)" (LRO Diviner). Any new source must be the same kind of number and be labelled in `DIMENSION_SOURCES` in `data/scores_html.py`.
- Only max ground temperature vs Malapert is scored so far. Arcadia has no ground-temperature value, so its card says "no data".
- Target rows with "(reference)" in the name are not scored; they appear on the gap page only.

## Scoring rules
- Score each dimension separately: 1 = same value as the target, 0 = as different as anything in the dataset.
  Formula: score = 1 - abs(earth_value - target_value) / (max - min of that column across all rows), clipped to 0..1.
- Never combine dimensions into one overall number unless a teammate asks.
- A blank cell means "no data": skip it and show "no data" in charts. Never invent, estimate or fill in values.
- Show a radar chart only for sites with at least one real score; otherwise show a clear "not scored yet" note.
- The main content is the site pages, the gap page ("Where Earth falls short") and the task table. The task table is team judgment, not computed, and must say so.
- Every site page must show the "matches" and "breaks" text, plus a fixed note that Earth cannot reproduce lunar or Martian gravity, vacuum or thin atmosphere, or radiation.

- Comment every step in plain English. A teammate who knows basic Python must be able to follow it.
